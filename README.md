# Bo Shi — Academic Homepage

Personal academic website for Bo Shi (史博).

**URL:** `https://<your-username>.github.io`

## Deploy to GitHub Pages

1. Create a new repository on GitHub named `<your-username>.github.io`
2. Push these files to the repository
3. Go to Settings → Pages → deploy from `main` branch `/` (root)
4. Your site will be live at `https://<your-username>.github.io`

### Or use any repository

1. Create any repository (e.g., `bo-shi-homepage`)
2. Push files to `main` branch
3. Go to Settings → Pages → Source: `GitHub Actions` or `main` branch `/docs` folder
4. Site will be live at `https://<your-username>.github.io/bo-shi-homepage`
